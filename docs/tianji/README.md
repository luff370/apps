# 天纪命理独立知识包

这个目录只包含“天纪命理”相关内容，方便接入其他 AI 应用。它不依赖根目录的中医 Skill，也不会加载六经辨证、方剂和医疗回答规则。

## 当前应用覆盖范围

- 紫微斗数十四主星、十二宫位和程序生成的命盘/运势报告解读。
- 易经起卦、八字和阳宅风水暂不接入当前应用。

## 文件说明

```text
tianji/
├── README.md                 # 接入说明
├── SYSTEM_PROMPT.md          # 可直接用于模型 system message
├── CHAT_CONTRACT.md          # 输入输出协议与示例
└── knowledge/
    ├── tianji.md             # 独立知识库
    └── index.json            # 机器可读的分区和关键词索引
```

## 最小接入

1. 只检索 `knowledge/tianji.md` 中的“天纪·天机道”章节。
2. 将 `SYSTEM_PROMPT.md` 作为 system prompt。
3. 把用户问题和必要的结构化资料传给模型。
4. 涉及排盘、起卦或户型分析时，先由程序计算，再把计算结果交给模型解释。

## 需要程序计算的内容

模型不应凭记忆完成以下计算：

- 紫微斗数：历法转换、命宫/身宫、星曜落宫、大限流年
- 六十四卦：起卦方式、本卦、动爻、变卦
- 阳宅风水：坐向、门窗和房间位置、户型图空间关系

推荐的调用链：

```text
用户输入 → 参数校验 → 命理计算工具 → 检索本目录知识 → 模型解释 → JSON 校验 → 前端展示
```
