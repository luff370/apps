# 倪师问诊紫微调用协议

## 请求格式

请求由四部分组成：用户问题、检索出的紫微知识片段、最近对话，以及可选的程序计算报告。个人命盘分析必须包含程序计算报告；没有报告时只能回答通用紫微知识或提示用户选择命盘。

## 响应格式

回答必须依次包含 `【已知资料】`、`【计算结果】`、`【知识依据】`、`【综合解读】`、`【行动建议】`，并以“说明：内容仅供传统文化研究和自我观察参考”结束。客户端会校验这些字段；缺失时会要求模型自动纠正一次。

个人报告解读不能只概括结论：至少引用 3 项已计算资料，完成 2 条“程序结果 → 知识依据 → 现实表现 → 条件或限制”的推理链，并交代支持信号、制约因素及主次关系。行动建议应按优先级给出 3 至 5 条，每条包含适用场景、具体动作和可观察反馈。

## 路由建议

| 用户意图 | 处理方式 |
|---|---|
| 十四主星、十二宫位等通用知识 | 检索紫微知识后回答，不生成个人结论 |
| 事业、婚姻、财帛等个人分析 | 校验已选命盘并调用报告引擎，再交给模型解释 |
| 易经、八字、风水等非紫微问题 | 说明当前仅支持紫微斗数 |
