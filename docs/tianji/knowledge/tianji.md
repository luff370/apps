# 天纪体系

> 本文件是项目原有天纪章节的独立提取版，供 RAG 或模型上下文使用。

## 总纲

天纪分为天机道、人间道、地脉道：天机道以紫微斗数分析人的命运格局；人间道以易经六十四卦阐释人事进退；地脉道以易经卦象配合地理形势分析阳宅。三者共同构成“天、人、地”三才体系。

### 地天泰重点

地天泰象征内健外顺、天地交泰。泰与否只隔一念：内在有实力，外在谦和守礼，事情容易通达；外表强硬而内里空虚，则容易转为否。用于人事解读时，重点是包容、守正、顺时，而不是承诺具体吉凶日期。

## 天纪·地脉道

地脉道把易经卦象与地理形势结合，用于解释阳宅对事业、婚姻和居住感受的影响。必须先取得房屋的坐向、朝向、门窗和空间布局，不能只凭一句“我家风水怎么样”下结论。

### 地理五要

- **龙**：山脉走势，主贵贱
- **穴**：聚气之处，主吉凶
- **砂**：周围山势，主护持
- **水**：水流方向，主财运
- **向**：坐向方位，主纳气

### 阳宅解读边界

阳宅解读应描述“在该传统体系下如何理解这个布局”，并说明依据和不确定性。不要把住宅布局与疾病、财富或婚姻结果建立确定因果关系，也不要在没有户型资料时编造方位判断。
